## Manual browser checklist (gate item 18)

Once Tasks D–E land, verify in a browser (`npm run dev`, real DB + Gemini):

1. Open `/`; it creates a session and routes to `/session/<id>`.
2. Teach the scripted cycle 1 (omit the base case). The student turn shows
   *Evaluating* then *Evaluated*; a learner probe appears.
3. The concept map shows `base_case` not demonstrated and is labelled with the
   record version; "Assess my learner" is enabled.
4. Start an attempt; answers reveal one at a time; the termination question is
   `misconception`/`partial` with `base_case` blocking.
5. Refresh mid-session — the state restores identically (hydrate).
6. Double-click **Send** on one explanation — only one student turn and one
   learner response appear (idempotency), no duplicate record.
